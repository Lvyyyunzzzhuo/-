# -
本作品为面向城市交通治理的 FPGA 道路交通模拟器，针对车流不均、路口拥堵、干线协调不足、行人干扰问题，搭建分层智能仿真管控平台。 系统分决策、执行两层。决策层以 FPGA 为边缘计算核心，依靠并行实时运算，统一管理三类场景，板载按键实现场景选择、参数调整、启停与一键复位。 执行层包含三大仿真：绿波车道可设置车速与相位差，实现干线绿波通行，对比绿波带宽；红绿灯支持固定、自适应配时，自适应模式根据人车流量动态分配绿灯时长；潮汐车道切换前预警检测车道，有滞留车则取消切换，预留应急通道保障特种车辆优先通行。 数据经串口上传电脑与云端，支持远程监控、历史回放，可按拥堵等级联动可变限速。本平台集成多场景仿真、智能控制与人机交互，服务智慧交通仿真研究。
